**QUICKNOTES**

**Description**
**QuickNotes** is a simple, responsive note-taking web application built using HTML, CSS, and JavaScript. It allows users to create and organize notes into Personal, Work, and Study categories, search notes by keywords, and delete notes when they are no longer needed. The application includes input validation to ensure notes are not empty or longer than 200 characters, displays the date and time each note was created, and automatically updates the total number of notes. Using browser localStorage, QuickNotes saves notes so they remain available after the page is refreshed, providing a convenient and user-friendly way to manage everyday information and stay organized.

**Features**
1. Add Notes
2. Categorize notes
3. Display notes
4. Delete notes
5. Search notes
6. Input validation
7. LOcal storage
8. Category based styling
